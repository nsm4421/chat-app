# feature_community

`feature_community`는 플레이 결과를 공유하고 반응하는 커뮤니티 기능 패키지다.

이 패키지는 인증 게시글, 댓글, 반응, 피드 같은 사용자 간 상호작용을 담당한다.

## 책임

- 플레이 결과 인증 게시글
- 피드 조회
- 댓글
- 반응
- 신고와 moderation 확장 포인트

## 패키지 의미

이 패키지는 `플레이 이후 공유와 상호작용의 경계`다.
핵심 투자 로직과 랭킹 계산과는 분리해, 커뮤니티 기능이 커져도 투자 기능을 오염시키지 않게 만든다.

## 포함하지 않는 것

- 로그인/프로필 관리
- 투자 세션 계산
- 시즌 랭킹 집계
