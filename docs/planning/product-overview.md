# 제품 개요

## 한 줄 정의

사용자가 기준 날짜를 선택하면 그 전 거래일의 코인 시세 replay를 실시간처럼 재생해, 가상의 돈으로 투자하고 성과를 경쟁하는 모의 투자 게임 앱.

## 문제 정의

기존 투자 학습 서비스는 아래 한계가 있다.

- 초보자에게 어렵고 진입 장벽이 높다.
- 실전 투자와 연결되면서 심리적 부담이 크다.
- 학습보다 정보 소비에 치우치기 쉽다.
- 기록과 성과를 게임처럼 즐기기 어렵다.

이 앱은 `실전 돈 없이`, `선택한 날짜 기준 전 거래일 replay 데이터로`, `실시간 투자앱 같은 감각으로 반복 플레이`할 수 있게 만드는 것을 목표로 한다.

## 목표 사용자

### 1. 투자 입문자

- 코인 투자에 관심은 있지만 실전은 부담스럽다.
- 손실 없이 연습하고 싶다.

### 2. 경쟁형 사용자

- 랭킹, 시즌전, 수익률 비교 같은 요소를 좋아한다.
- 자신의 플레이를 인증하고 싶다.

### 3. 콘텐츠 소비형 사용자

- 다른 유저의 전략, 인증, 결과를 보며 즐긴다.
- 커뮤니티에서 반응을 얻고 싶다.

## 핵심 가치 제안

- `부담 없는 투자 연습`: 실돈이 아니라 가상 자산으로 플레이
- `실시간 같은 긴장감`: 과거 시장을 단순 조회가 아니라 재생 흐름 안에서 플레이
- `반복 가능한 게임 루프`: 한 번의 투자보다 여러 판의 플레이
- `결과 중심 재미`: 수익률, 자산, 승률, 회차별 기록
- `커뮤니티 확장성`: 인증, 랭킹, 전략 공유, 시즌전

## 제품 포지셔닝

- 투자 도구보다는 `투자 시뮬레이션 게임`
- 거래소 앱 감각을 차용한 `코인 replay 투자 게임`
- 채팅 중심 커뮤니티보다는 `성과 중심 커뮤니티`

## MVP 범위

- 회원가입 / 로그인
- 기본 프로필
- 게임 머니 지급
- 플레이 기준 날짜 선택
- 기준 날짜의 전 거래일 replay 데이터 기반 플레이 세션 시작
- 코인 매수 / 매도
- 손익 계산
- 플레이 종료 결과 저장
- 개인 기록 조회
- 간단한 랭킹

## MVP에서 제외

- 실시간 시세 거래
- 실시간 외부 시장과 직접 동기화되는 거래
- 실제 자산 연동
- 고급 주문 방식
- 호가 기반 체결 엔진
- 복잡한 소셜 기능
- 고급 길드 / 클랜 기능
- 실시간 채팅

## 성공 지표 초안

- 첫 플레이 완료율
- 3일 이내 재플레이율
- 평균 플레이 세션 수
- 시즌 랭킹 참여율
- 결과 공유 / 인증 생성 비율
