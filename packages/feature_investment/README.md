# feature_investment

`feature_investment`는 모의 투자 플레이 자체를 담당하는 핵심 패키지다.

이 패키지는 사용자가 replay 시장 안에서 플레이를 시작하고, 주문하고, 포지션을 관리하고, 손익을 계산하는 책임을 가진다.

## 책임

- 플레이 세션 시작/종료
- 가상 잔고 관리
- 매수/매도 주문 처리
- 포지션 관리
- 손익 계산
- 플레이 결과 저장

## 패키지 의미

이 패키지는 `유저 플레이 상태와 투자 규칙의 중심 경계`다.
시장 데이터는 `feature_market`에서 읽고, 그 데이터를 바탕으로 실제 게임 진행 상태를 만든다.

## 포함하지 않는 것

- replay 원본 시장 데이터 적재
- 시즌 랭킹 집계
- 커뮤니티 게시물 관리
