# Mobile Mock UI

`apps/mobile`은 현재 실제 데이터 연결 전 단계의 mock UI 셸로 구성했다.

## 화면 구성

### 1. Home

- 탭 4개로 전체 제품 흐름을 요약한다.
- `플레이`: replay 시나리오와 게임 루프 소개
- `거래`: 거래소 느낌의 세션 미리보기
- `인증`: 수익 인증 피드 미리보기
- `랭킹`: 시즌 경쟁 구조 미리보기

### 2. Replay Setup

- 어떤 날짜와 시나리오로 플레이를 시작할지 고르는 화면
- 세션 규칙, 난이도, 보상, 체크리스트를 한 번에 보여준다
- 핵심 목적은 "들어가기 전 기대감 형성"

### 3. Trading Session

- 차트, 주문 패널, 체결 테이프, 포지션을 한 화면에 배치
- 실제 거래 앱처럼 보이는 감각을 시연하는 화면
- 핵심 목적은 "플레이 중 긴장감 전달"

### 4. Session Result

- 수익률, 체결 회고, 인증 카드 미리보기를 보여준다
- 결과 저장 이후 어디로 이동할지 액션을 제안한다
- 핵심 목적은 "플레이 결과를 콘텐츠로 전환"

### 5. Proof Detail

- 인증 카드 본문, 반응 수치, 댓글형 코멘트, 연관 플레이를 보여준다
- 채팅보다 성과 중심 커뮤니티라는 방향을 강조한다

### 6. Season Detail

- 시즌 소개, 보상 티어, 랭킹, 주간 미션을 보여준다
- 반복 플레이와 경쟁 동기를 강화하는 구조다

## 의도

- 거래 자체보다 `replay 투자 게임`의 정체성이 먼저 보이게 한다
- 채팅 중심 앱이 아니라 `플레이 -> 결과 -> 인증 -> 경쟁` 흐름이 자연스럽게 이어지게 한다
- 이후 실제 데이터 연결 시에도 지금 만든 화면 구조를 그대로 뼈대로 사용할 수 있게 한다
