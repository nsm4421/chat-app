# Product Planning

이 디렉터리는 `domodachi`의 제품 기획 문서를 모아 둔 공간입니다.
한 문서에 모든 내용을 몰아넣지 않고, 읽는 목적에 따라 나눠 관리합니다.

## 먼저 읽을 문서

1. [Product Overview](./product-overview.md)
2. [Identity Policy](./identity-policy.md)
3. [User Flows](./user-flows.md)
4. [Roadmap](./roadmap.md)

## 문서 역할

- [Product Overview](./product-overview.md)
  - 서비스 정체성, 핵심 가치, 기획 확정 사항을 정리합니다.
- [Identity Policy](./identity-policy.md)
  - 익명 상태와 프로필 공개 상태를 언제 어떻게 전환할지 정리합니다.
- [User Flows](./user-flows.md)
  - 사용자가 어떤 순서로 익명 대화에서 친구 관계로 넘어가는지 정리합니다.
- [Roadmap](./roadmap.md)
  - 현재 구현 기준과 TODO를 체크리스트로 관리합니다.

## 체크리스트 규칙

- `[x]` : 방향이 확정되었거나 현재 구현 기준으로 반영된 항목
- `[ ]` : 아직 미구현이거나 기획 결정이 더 필요한 항목
