# Product Overview

## 한 줄 정의

`domodachi`는 익명으로 대화를 시작하고, 서로 원할 때만 친구가 되어 프로필을 공개하는 채팅 앱입니다.

## 제품 정체성

이 앱은 아래 두 가지를 함께 가져가려는 제품입니다.

- 처음 만날 때의 낮은 진입장벽
- 관계가 쌓였을 때의 지속 가능한 연결

즉, 완전 익명 앱보다는 `익명에서 관계로 전환되는 앱`에 가깝습니다.

## 핵심 가치

- 익명 대화의 부담이 낮다.
- 친구 수락 전까지 신원 노출이 없다.
- 관계가 형성되면 친구 기반 경험으로 자연스럽게 전환된다.

## 지금 기준의 핵심 메시지

- 익명으로 시작한다.
- 친구가 되기 전까지는 익명으로 남는다.
- 친구가 되면 프로필이 공개된다.

## 기획 확정 사항

- [x] 그룹채팅에서는 익명으로 대화한다.
- [x] 친구 요청을 보낸 시점만으로는 프로필을 공개하지 않는다.
- [x] 친구 요청을 수락하기 전까지는 서로 익명 상태를 유지한다.
- [x] 친구 수락 후에만 프로필을 공개한다.
- [x] 친구 관계가 생기면 익명 대화와 별도의 친구 관계 경험을 제공한다.

## 현재 구현 기준으로 반영된 축

- [x] 인증 기반 앱 구조를 사용한다.
- [x] 프로필 설정 흐름이 존재한다.
- [x] 친구 요청/수락/거절/취소/삭제 도메인이 존재한다.
- [x] 공개 그룹채팅 탐색과 참여 흐름이 존재한다.
- [x] 개인 채팅 탭과 친구 탭이 앱 구조에 포함되어 있다.
