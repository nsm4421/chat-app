# feature_ranking

`feature_ranking`은 플레이 결과를 비교하고 시즌 경쟁 구조를 다루는 패키지다.

이 패키지는 유저의 세션 결과를 읽어 리더보드, 시즌 순위, 통계성 결과를 제공하는 책임을 가진다.

## 책임

- 시즌 목록 조회
- 리더보드 조회
- 수익률 순위 계산 결과 표시
- 유저별 성과 요약
- 모드별 랭킹 구분

## 패키지 의미

이 패키지는 `경쟁과 비교의 경계`다.
실제 플레이는 `feature_investment`가 담당하고, 그 결과를 랭킹 규칙에 맞게 읽고 보여주는 역할을 맡는다.

## 포함하지 않는 것

- 투자 주문 처리
- 포지션 계산
- 커뮤니티 게시글 작성
