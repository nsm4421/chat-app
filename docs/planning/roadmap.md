# 로드맵

## 1단계: 코어 게임 MVP

목표: 모의 투자 플레이가 끝까지 돌아가게 만들기

- 인증
- 기본 프로필
- 게임 머니 지급
- 과거 시세 데이터 조회
- 매수 / 매도
- 포트폴리오 계산
- 플레이 종료 및 결과 저장
- 내 전적 보기

## 2단계: 경쟁 요소 추가

목표: 혼자 하는 플레이에서 비교 가능한 플레이로 확장

- 챌린지 모드
- 시즌 단위 플레이
- 랭킹 보드
- 결과 인증 카드
- 대표 성과 지표 정리

## 3단계: 커뮤니티 확장

목표: 플레이 기록이 콘텐츠가 되게 만들기

- 인증 피드
- 댓글 / 반응
- 친구 기능
- 친구 간 비교
- 상위 플레이어 소개

## 4단계: 고급 메타 시스템

목표: 장기 잔존을 위한 메타 게임 추가

- 유저 평판
- 배지 / 업적
- 시즌 보상
- 부정 플레이 탐지
- 운영자 제재 도구

## 5단계: 콘텐츠 고도화

- 튜토리얼 시나리오
- 난이도별 미션
- 시장 이벤트 기반 플레이
- AI 해설 또는 회고 기능
- 전략 리플레이
