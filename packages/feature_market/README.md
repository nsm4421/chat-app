# feature_market

`feature_market`은 replay 가능한 시장 데이터를 읽어오는 기능 패키지다.

이 패키지는 사용자가 플레이를 시작하기 전에 필요한 시장 정보와, 플레이 중 화면에 보여줄 시장 데이터를 담당한다.

## 책임

- replay 가능한 날짜 목록 조회
- 코인 종목 목록 조회
- replay tick 조회
- replay candle 조회
- 시장 상세 화면용 read model 구성

## 패키지 의미

이 패키지는 `시장 데이터 읽기 전용 경계`다.
즉 사용자 자산, 주문, 손익 계산은 여기서 하지 않고 `feature_investment`가 담당한다.

## 포함하지 않는 것

- 매수/매도 주문 처리
- 가상 잔고 계산
- 포지션 관리
- 랭킹 계산
