# 커뮤니티와 랭킹

## 방향

커뮤니티는 단순 대화 공간이 아니라 `플레이 결과를 중심으로 모이는 공간`으로 설계한다.

핵심은 아래 세 가지다.

- 플레이 결과 인증
- 시즌 / 모드별 랭킹
- 전략과 플레이 기록 공유

## 주요 기능

### 결과 인증

- 사용자는 특정 플레이 결과를 게시할 수 있다.
- 인증 내용 예시
  - 총 수익률
  - 최종 자산
  - 승률
  - 플레이 기간
  - 사용 코인
- 결과는 시스템 기록과 연결돼야 한다.
  - 임의 텍스트 입력만으로는 인증으로 취급하지 않는다.

### 랭킹

- 일간 / 주간 / 시즌 랭킹
- 모드별 랭킹 분리
- 주요 랭킹 지표
  - 수익률
  - 최종 자산
  - 최대 손실 방어율
  - 챌린지 성공 횟수

### 피드

- 유저 인증 글
- 상위 랭커 하이라이트
- 특정 코인 챌린지 결과 모음
- 친구 / 팔로우 유저 활동

## 확장 아이디어

### 친구

- 친구 추가
- 친구끼리 성과 비교
- 친구 전용 미니 랭킹

### 유저 평판

- 전략 공유 신뢰도
- 시즌 성실 참여도
- 신고 누적 / 제재 이력 반영 가능

### 유저 제재

- 부정 플레이 탐지
- 악성 커뮤니티 활동 제재
- 랭킹 제외 / 시즌 참여 제한

## 운영상 중요 포인트

- 랭킹 기준은 명확해야 한다.
- 인증 게시물은 실제 플레이 결과와 연결돼야 한다.
- 커뮤니티 보상은 부정행위 유인을 만들지 않게 설계해야 한다.
- 시즌 종료와 정산 규칙은 사전에 고정해야 한다.
